# Divano-elegante prompt

# The visual direction I recommend

I would position Divano Elegante visually somewhere between:

**Luxury furniture showroom × premium architectural studio × modern workplace brand**

Think:

> **"Designed spaces. Exceptional comfort."**
>

# 1. Your color system

Your current logo is navy + yellow, so I wouldn't suddenly make the whole website green like VibeCrafts.

I'd build the brand around:

### Primary

**Midnight Navy**

`#10263D`

Use for:

- header
- buttons
- dark sections
- footer
- important text

### Secondary

**Champagne Gold**

`#C6A15B`

Use very sparingly for:

- borders
- icons
- small labels
- decorative lines
- hover states
- premium accents

### Main background

**Warm Ivory**

`#F7F4EE`

This is extremely important.

Don't make the entire website pure `#FFFFFF`.

Use:

```
#F7F4EE
```

for major sections.

### Dark background

**Deep Navy**

`#0C1D2D`

Use for:

- footer
- selected hero sections
- brand story

### Neutral

**Warm Stone**

`#D9D2C5`

Use for cards/borders.

### Text

Primary:

`#18212B`

`#69717A`

# 25. Don't overuse gold

This is important.

Gold is one of the easiest ways to accidentally make a website look cheap.

Use it like jewelry.

### Good

```
────────────────
    •
SHOP NOW →
```

small gold line/icon.

### Bad

```
GOLD BUTTON
GOLD BORDER
GOLD TEXT
GOLD CARD
GOLD BACKGROUND
GOLD ICON
```

Keep approximately:

**80% ivory/white + 15% navy + 5% champagne**

VibeCraft can get away with it because they have a massive catalog.
